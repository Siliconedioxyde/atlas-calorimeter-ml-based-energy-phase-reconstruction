# ATLAS Calorimeter ML-Based Energy & Phase Reconstruction

This repository contains my paper and supporting code for **signal reconstruction in the ATLAS calorimeter using machine learning**.  
It includes the analysis scripts, explanatory text, and final submission materials used in the project.

## Contents
- `paper.pdf` — Full paper
- `Bonuspart.py` — Additional analysis routines
- `dataViewer.py` — Script for visualizing calorimeter data
- `linearModel.py` — Baseline linear model implementation
- `readingnpz.py` — Loader for `.npz` datasets used in experiments
- `FiguresOfMerit.pdf` — Performance metrics and evaluation figures
- `FinalSubmission.pdf` — Final compiled submission

## Summary
The ATLAS calorimeter produces complex signals that require accurate reconstruction for physics analysis.  
In this work, I:
- Applied machine learning models to reconstruct calorimeter signals.
- Benchmarked ML approaches against conventional reconstruction techniques.
- Demonstrated improvements in accuracy and robustness for certain event classes.
